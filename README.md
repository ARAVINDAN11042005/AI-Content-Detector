# ⚡ AI Content Detector

> Full-stack forensic web application that detects whether an image or video was generated by AI, displaying a confidence percentage, dynamic circular progress gauge, frame-by-frame breakdown, and an analytics dashboard.

---

## 🌟 Key Features

- **Drag & Drop Upload Zone**: Supports images (`jpg`, `jpeg`, `png`, `webp`) and videos (`mp4`, `webm`) up to 50MB.
- **Client-Side Live Preview**: Instant media preview with file size, dimensions, and format tags before running analysis.
- **Dual AI Detection Engine**:
  - **Sightengine GenAI API Integration**: Connects to Sightengine deep learning endpoints via `.env`.
  - **Local Forensic Heuristic Engine (Offline / Fallback)**:
    - Camera hardware EXIF metadata verification.
    - AI generator fingerprint header scanning (Stable Diffusion, Midjourney, ComfyUI, DALL-E, etc.).
    - High-frequency sensor grain / noise residual variance analysis.
    - Laplacian micro-texture and edge gradient analysis.
    - Saturation distribution & standard diffusion canvas dimensions (512, 768, 1024, etc.).
- **Multi-Frame Video Deconstruction**:
  - Extracts evenly spaced frames using OpenCV.
  - Analyzes each frame individually and visualizes frame snapshot cards with timestamps and individual confidence scores.
- **Interactive Results Page**:
  - Animated circular progress gauge with count-up percentage counter.
  - Color-coded badges: 🟢 Real (0–30%), 🟡 Uncertain (31–69%), 🔴 AI Generated (70–100%).
  - Detailed forensic signal breakdown cards.
- **Scan History & Analytics Dashboard (`/dashboard`)**:
  - Top KPI cards: Total Scans, AI Detected, Real Content, and Scans This Week.
  - Real-time search by filename.
  - Category filter pills: All, Images, Videos, AI Generated, Real, Uncertain.
  - Individual scan record deletion with automatic disk cleanup.

---

## 🛠️ Tech Stack

- **Backend**: Python 3.12, Flask, Flask-SQLAlchemy, Werkzeug
- **AI & Forensics**: OpenCV (`cv2`), Pillow (`PIL`), NumPy, Requests
- **Database**: SQLite with SQLAlchemy ORM
- **Frontend**: Modern Vanilla HTML5, CSS3 (Glassmorphism & Dark Navy Theme), Vanilla JavaScript (ES6+)

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/ARAVINDAN11042005/AI-Content-Detector.git
cd AI-Content-Detector
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Environment Variables (Optional)
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Add your Sightengine credentials if you wish to use the cloud model:
```env
SIGHTENGINE_API_USER=your_user_id
SIGHTENGINE_API_SECRET=your_secret_key
```
*(If left empty, the application runs entirely offline using the local forensic heuristic engine!)*

### 4. Run the Application
```bash
python app.py
```
Visit `http://127.0.0.1:5000` in your web browser.
